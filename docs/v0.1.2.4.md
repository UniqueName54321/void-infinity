# v0.1.2.4

## Multitaps in all four modes

Right-click a normal note and choose **Configure multitap**. The existing tap-count,
time-signature, and subdivision controls now work for standard circles, taiko hits,
catch fruits, and mania notes. Setting the count to 1 restores a normal note.
Each required note receives its own judgement; the group itself adds no extra
judgement. Editor changes support undo and redo, and native `.vib`/`.vibz` files
preserve the group. Older native maps remain supported.

- Standard uses repeated clicks at the authored position.
- Taiko uses repeated native drum hits, retaining hit colours and strong hits.
- Catch uses repeated fruits at the authored position, caught with normal movement.
- Mania uses repeated key presses in the authored column.

Standard multitaps can also be converted to the other built-in modes. This does
not turn the group's duration into a spinner, swell, shower, or hold note.

## No Multis

**No Multis** is available under conversion mods in every mode. It creates ordinary
streams from the groups before the usual gameplay/mod processing. Timing follows
the authored rhythm and tempo changes; individual hitsounds and native note
properties are retained. The saved beatmap is not changed. Like other new fork
features, the mod is unranked and unavailable for multiplayer.

## Star estimates

Difficulty calculations use the complete required-note sequence rather than one
parent per group. This updates strain, hit counts, combo, and score attributes
consistently. Calculation uses a separate object list so it cannot flatten a
cached gameplay map.

For native standard sliders, the calculator samples the moving path and velocity
profile over time. It measures required tracking distance and speed variation,
and gives tracking strain to first/standalone extended sliders too. Sampling is
bounded to keep long sliders manageable. Ordinary static-slider calculations
retain their existing path model.

All four calculator versions are bumped, invalidating old calculation results.
These are local heuristic estimates, not a calibrated guarantee of human difficulty;
extreme authored patterns can still be harder or easier than their star count.

## Mod compatibility

Relax now handles each standard tap. Autoplay handles the full sequence in all
modes, including interleaved catch objects. Visibility mods affect child notes
instead of fading their entire group early; the count label is suppressed under
Hidden and its derived visibility mods so it does not reveal hidden patterns.
The mandatory Human Play autoplay badge remains independent and visible.

Mania column changes and standard/catch position changes propagate to the child
notes. Taiko Swap and Random affect each hit; Simplified Rhythm expands groups
before rewriting their rhythm. Unusual combinations of experimental fun mods
remain experimental; automated checks cover the main interactions above.

No networking, account, or data-directory changes are introduced by this update.
